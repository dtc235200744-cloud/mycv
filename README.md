# 💼 MyCV - Hồ Sơ Năng Lực Trực Tuyến & Chuẩn In Ấn

> Trang CV & Portfolio cá nhân chuyên nghiệp của **Ma Đình Tiến** (Cloud & Full-Stack Developer), được xây dựng bằng **HTML5 Semantic, CSS3 hiện đại và Vanilla JavaScript**.

![Preview](assets/avatar.jpg)

## 🌟 Điểm nổi bật (Key Features)

- 🎨 **Thiết kế Glassmorphism Hiện Đại**: Giao diện sang trọng, màu sắc hài hòa, hiệu ứng chuyển động mượt mà.
- 🌓 **Hỗ trợ 2 Chế độ Giao diện (Dark / Light Mode)**: Tự động ghi nhớ tùy chọn hiển thị bằng `localStorage`.
- 🌐 **Hỗ trợ Song Ngữ (Bilingual VI / EN)**: Chuyển đổi linh hoạt giữa Tiếng Việt và Tiếng Anh chỉ với 1 cú nhấp chuột.
- 🖨️ **Tối ưu hóa In ấn & Xuất PDF (@media print)**: Định dạng chuẩn khổ giấy A4, ẩn các thanh công cụ thừa, chống tràn trang tự động.
- 📱 **Tương thích mọi thiết bị (Responsive Design)**: Hiển thị hoàn hảo trên Desktop, Máy tính bảng (Tablet) và Điện thoại di động (Mobile).
- 📋 **Tương tác nhanh**: Bấm để sao chép địa chỉ email kèm thông báo Toast nổi, liên kết trực tiếp tới GitHub và LinkedIn.
- 🚀 **Chuẩn SEO & Tải siêu nhanh**: Sử dụng HTML/CSS/JS thuần, không phụ thuộc thư viện nặng nề, tối ưu điểm Google Lighthouse 95+.

## 🛠️ Hướng dẫn xem & Chạy thử nghiệm

### 1. Mở trực tiếp trên máy tính
Chỉ cần nhấp đúp chuột vào file `index.html` hoặc mở bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Safari).

### 2. Kích hoạt GitHub Pages để xem online
1. Truy cập repo trên GitHub: `https://github.com/dtc235200744-cloud/mycv`
2. Vào mục **Settings** -> **Pages**.
3. Tại phần **Build and deployment** > **Branch**, chọn nhánh `main` và thư mục `/(root)`.
4. Nhấn **Save**. Sau khoảng 1 phút, trang web sẽ hoạt động trực tuyến tại địa chỉ:
   👉 **`https://dtc235200744-cloud.github.io/mycv/`**
